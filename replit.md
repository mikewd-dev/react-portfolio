# React Portfolio Project

## Overview
This is a React-based portfolio website built with Vite that showcases projects and skills. The application uses React Router for navigation, Bootstrap for styling, and FontAwesome for icons.

## Project Structure
- **Frontend**: React application with Vite build system
- **Styling**: Bootstrap CSS framework with custom CSS
- **Components**: Modular React components for different sections (Header, Projects, Skills, Contact, etc.)
- **Data**: Project and skills data stored in JSON files

## Technical Stack
- React 18.2.0
- Vite 5.0.8 (build tool)
- React Router DOM (routing)
- Bootstrap 5.3.2 (styling)
- FontAwesome (icons)
- Various React utilities (react-responsive, react-popper, etc.)

## Key Features
- Responsive portfolio layout
- Project showcase with images and descriptions
- Skills section with technology icons
- Contact information
- Clean, modern design

## Development Setup
- **Dev Server**: Runs on port 5000 with hot reload
- **Host Configuration**: Configured for 0.0.0.0 to work with Replit proxy
- **Build System**: Vite with React plugin

## Deployment Configuration
- **Target**: Autoscale (static website)
- **Build**: npm run build (creates dist folder)
- **Run**: npm run preview (serves built files)
